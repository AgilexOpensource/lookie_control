# lookie_control

ROS 2 control and teleoperation packages for the Lookie robot.

- [lookie_teleop](lookie_teleop/README.md): VR teleop logic (xr_media_ros -> kstone tasks). Its launch starts only the teleop node.
- [kstone_mock](kstone_mock/README.md): MuJoCo whole-body IK stand-in for kstone_ros until the real control layer is ready.
